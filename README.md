# 💰 Controle Financeiro Automatizado

Sistema de controle financeiro pessoal desenvolvido utilizando Google Sheets e Google Apps Script.

O projeto nasceu da necessidade de automatizar tarefas recorrentes de organização financeira, transformando uma planilha tradicional em uma ferramenta com regras de negócio, automações e interfaces próprias.

## 🚧 Status

Em desenvolvimento.

## ✨ Funcionalidades atuais

- Dashboard financeiro mensal
- Controle de receitas
- Controle de despesas fixas e variáveis
- Controle de parcelamentos
- Cálculo automático de parcelas restantes
- Atualização por mês de referência
- Cadastro de parcelamentos através de formulário
- Importação de faturas em PDF
- Extração de transações de faturas
- Revisão das despesas antes da importação
- Categorização de despesas
- Controle de despesas por responsável
- Proteção contra importações duplicadas
